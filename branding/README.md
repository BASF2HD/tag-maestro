# Tag Maestro identity

The header, favicon and desktop icon use one bold amber music-tag mark.
Source: Codex built-in image editor (2026-10-10); no paid API or LaMa.
Creative-production guided the small-space silhouette; imagegen produced the raster master.

Prompt: Flat bold amber music price-tag with one charcoal eighth-note cutout, centered on a charcoal square. No text, hearts, fine lines, shadows or 3D. Prioritize recognition at 16 pixels.

`public/brand/tag-maestro-1024.png` is the shipped master. Deterministic PNG exports are 16, 32, 48, 64 and 180 pixels. `public/favicon.ico` contains 16, 32 and 48 pixel PNG-backed entries. Desktop PNG/ICNS are generated by `scripts/build-desktop-icon.mjs` from the same master. No separate logo system is used.
