A few things to know.

Can I use the app without installing it?

Yes. On Mac, extract the app ZIP and open Tag Maestro.app. On Windows, use the Portable EXE. Packaged apps need no Node.js, development server or separate browser.

Does the browser version rename original folders?

No. Native in-place folder/archive renaming requires the desktop app. The browser version supports compatible music-tag editing and original-file saving where browser permissions allow it.

How does cover cleanup work?

Export a Codex cover-cleanup batch, edit it separately, then import and compare the results. Only approved artwork is written. The app does not silently run an AI image service or remove album titles and logos.

What should I back up?

Keep backups before editing original tags or artwork. Song deletion is immediate and permanent. Choosing overwrite for a name conflict preserves the old destination as a hidden sibling backup; folders are replaced, not merged.
